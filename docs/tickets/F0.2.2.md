# Ticket F0.2.2: Serial Numbers MVP (Offline-First)

## Objective

Enable internal users to manage Serial Numbers inside an Inspection Report using offline-first capabilities.

## Architecture Guidelines

- **Tenant Isolation:** Explicit `tenantId` attached to Prisma `SerialNumber` model, mapped via database migration logic.
- **Offline Creation (Bulk):** Accepts string arrays mapping them into local `SerialNumberLocalRepo` tracking models synced utilizing outbox `BULK_CREATE` queued messages structurally bound to `{ clientRef, serialNumber }`. Remote sync returns matching sets that are immediately swapped locally (Atomic Temporal ID Remapping).
- **Offline Renaming:** Inline structural renaming tracked locally pending `SN_UPDATE` atomic concurrency updates relying strictly on integer `version` comparison checks `(tenantId, id, version)`. Gated natively to `status !== APPROVED` and `status !== CLOSED`.
- **Conflicts:** Uniqueness constraint applies exclusively across `[tenantId, inspectionReportId, serial]`. API correctly identifies payload inconsistencies and responds accurately via `409` structures mapping `alreadyExists[]` and `duplicatesInPayload[]`.
- **Audit Logging:** Bulk Creation utilizes single global AuditLog entries capturing quantitative scale rather than single logs to preserve database bandwidth. Renaming explicitly logs pre/post snapshot modifications.

## Manual Verification Steps

1. Start up the backend (`nx serve api`) and frontend (`nx serve portal`).
2. Navigate via the portal UI to an existing Inspection Report detail page.
3. Completely disable your network adapter / utilize browser offline tracking to force offline behavior.
4. Input three distinct serial strings (e.g., `A0`, `A1`, `A2`) separated by newlines within the text area. Click "Enqueue". Verify all items render accurately populated in the table tagged as `PENDING`.
5. Enter into Inline Edit mode by clicking "Edit" for `A0`. Change the term to `A0-Corrected` and utilize the Save action. Observe the table dynamically refresh its value.
6. Re-enable network adapter connectivity. Verify the background orchestrator dynamically processes the Outbox items asynchronously merging UUID temporal mappings. Watch the tags change dynamically from `PENDING` to `SYNCED`.
7. Hard refresh the browser to confirm server replication truth aligns fully with the local IndexedDB synchronization.
8. Attempt to transition the Report's Status to `CLOSED` or `APPROVED`. Revisit the Serial Numbers table to confirm the "Edit" visibility logic disappears ensuring strict compliance restriction.
