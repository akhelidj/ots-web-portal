# F0.3.2 - Export UI Integration MVP

## Context

This feature enables end users to cleanly download deterministic Snapshot datasets from Inspection Reports natively through the Portal UI.

## Architecture Guidelines

- **Strictly Online**: No Service Worker Outbox queueing is permitted. Validation checks assert `navigator.onLine`.
- **Approved Only Protection**: The "Export Snapshot" button remains visibly hidden until the report status is officially `APPROVED`.
- **Stateless Downloader**: The underlying `.ts` logic executes standard Blob fetching against `GET /inspection-reports/:id/export` without any global `/api` prefixes, interpreting status `0` universally as a network disconnnect to trigger safe validation blocks dynamically. Double-clicks are blocked via native boolean tracking visually backed by SVG spinners.

## Manual Verification Scenarios

**Scenario 1: Standard Extraction (<=10 Serials)**

- Login as Tenant User.
- Create an Inspection Report and finalize the workflow until Status marks `APPROVED`.
- Inject up to 10 matching Serial Numbers.
- Click `Export Snapshot`.
- An `.xlsx` file seamlessly downloads. Open and match content format validity.

**Scenario 2: Multi-Part Chunk Extraction (>10 Serials)**

- Reopen the report. Inject 15 total matching Serial Numbers.
- Approve report to trigger `PENDING_APPROVAL -> APPROVED` progression.
- Click `Export Snapshot` again.
- A `.zip` archive triggers cleanly encoding two chunked `.xlsx` reports (10 items / 5 items).

**Scenario 3: Validation State Gate (Draft)**

- Reopen the report (status maps to `DRAFT`).
- The `Export Snapshot` button entirely disappears from the DOM.
- Using an intercept tool directly curling `/inspection-reports/.../export` triggers a rigid `403 Forbidden`.

**Scenario 4: Hard Disconnect**

- Status is back to `APPROVED`.
- Use Chrome Developer Tools to throttle Network state cleanly to "Offline".
- Attempt clicking `Export Snapshot`. The UI surfaces an immediate `Export requires internet connection.` validation label cleanly blocking all outbounds.
