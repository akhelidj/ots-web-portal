# F0.1.1 Portal Shell + Navigation

## Overview
This document explains the implementation of the shared semantic application shell for the portal application as requested in F0.1.1.

## Mounting the Shell
The `ShellComponent` is mounted at the root of the portal's internal route structure in `src/app/app.routes.ts` (e.g. `path: ''`). All internal role-based areas (Admin, Receiver, Inspector, Supervisor) are defined as `children` of this shell. 

This enables Angular's router to render the internal pages inside the `<router-outlet>` provided by the single shell component layout.

## The "Single Shell" Rule
To ensure consistency and maintainability, the portal must follow the **Single Shell** rule for future development:
1. Components for individual pages or feature modules **must not** define their own global layout elements (`<header>`, `<nav>`, `<footer>`).
2. Global layouts are exclusively provided by the `ShellComponent`.
3. Feature pages merely render their domain-specific content via the `ShellComponent`'s main `<router-outlet>`.

## Semantic HTML Conventions expected for future pages
Future pages built within this shell must adhere to the following baseline accessibility and semantic HTML conventions:
1. **Meaningful Landmarks:** The document outline relies on correct usage of HTML5 semantic tags. Avoid generic `<div>` wrappers where an `<article>`, `<section>`, or `<aside>` is more appropriate.
2. **First Meaningful Element:** Every page mapped to a route must start with a descriptive `<h1>` representing the page's title or main context.
3. **No Inline Templates:** To separate concerns, all angular components must use external `.html` template files (using `templateUrl`) rather than inline templates.
4. **Accessibility (a11y):** The shell contains a hidden "Skip to content" link that targets the main container. Pages rendered within the `<main>` area do not need to implement their own skip links, but must ensure logical heading hierarchy (`<h1>`, `<h2>`, etc.) and proper ARIA labeling if native elements are insufficient.
